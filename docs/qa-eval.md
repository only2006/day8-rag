# Day 12 · 拒答能力评测（qa-eval）

> 评测脚本：`eval_refusal.py`
> 设计要点：**不走 qa.py 第一层阈值**，直接调模型，专门检验 prompt 层（第二层）的拒答能力。

## 方法

- 共 10 个问题：5 个「文档里能答」（检验会不会过度拒答），5 个「文档里没有」（检验会不会硬答/幻觉）
- 每组记录混合检索的向量相似度 `sim`（= 余弦相似度，qa.py 阈值判断用的就是它），用于观察两组分布、验证阈值不是拍脑袋定的

## 结果（2026-11-04）

**回答率 5/5，拒答率 5/5，综合正确率 10/10**

| 类型 | 问题 | sim | 结果 |
|---|---|---|---|
| 能答 | 登录功能改了什么 | 0.621 | 回答 ✓ |
| 能答 | 谁负责前端 | 0.531 | 回答 ✓ |
| 能答 | 接口响应时间优化了多少 | 0.748 | 回答 ✓ |
| 能答 | 充电一次能用多久 | 0.637 | 回答 ✓ |
| 能答 | 哪个型号防水级别最高 | 0.484 | 回答 ✓ |
| 拒答 | 公司的年假政策是什么 | 0.418 | 拒答 ✓ |
| 拒答 | 怎么申请报销 | 0.482 | 拒答 ✓ |
| 拒答 | Python 的 GIL 是什么 | 0.389 | 拒答 ✓ |
| 拒答 | 2024 年诺贝尔文学奖得主是谁 | 0.270 | 拒答 ✓ |
| 拒答 | 这个产品的保修期多久 | 0.550 | 拒答 ✓ |

## 阈值分析

- 能答组 sim 区间：`0.484 – 0.748`（最低 0.484）
- 拒答组 sim 区间：`0.270 – 0.550`（最高 0.550）
- 两组在 `0.48 – 0.55` 有重叠：例如「这个产品的保修期多久」sim=0.550，超过当前阈值 0.50，会进入模型层；但第二层 prompt 拒答生效，仍正确拒答。

**结论**：第一层阈值 0.50 不是完美分隔（重叠区靠第二层兜底），但两层叠加后 10/10 全对。
阈值由真实两组分布定出，非拍脑袋。后续若想更紧，可上调到约 0.55，但要承担漏答「哪个型号防水级别最高」(0.484) 的风险。

## 验收结论

Day 12 通过：能回答、能给 `[n]` 出处、文档外问题会拒答；**两层拒答机制均生效**。
